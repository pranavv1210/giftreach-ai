# API keys

All integrations are optional for local mock development. Gmail OAuth is required for future real delivery. `OPENAI_API_KEY` enables a future AI provider; rule templates work without it. `SEARCH_API_KEY` and `EMAIL_VERIFICATION_API_KEY` enable future permitted discovery and provider verification. `DATABASE_URL` selects local SQLite or hosted PostgreSQL. Provider pricing and free-tier limits vary; check the provider before enabling billing.
